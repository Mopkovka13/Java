**Вилка:** 200–350k ₽ на руки (архивная, ориентир).
**Обязанности:** декомпозиция бэклога, проектирование архитектуры и интеграций, разработка и тестирование backend-компонентов, code review, разбор инцидентов. Портал — 25 млн пользователей/мес.
**Обязательно:** Java от 1 года, Spring, SQL, системы сборки, unit-тесты.
**Желательно:** Jenkins, PostgreSQL, MyBatis, Docker, Kubernetes, OpenShift, WildFly.

## Что из этого следует

1. **Ядро одно и то же**: Java + Spring Boot + PostgreSQL + Kafka + Docker/OpenShift. Готовь именно это.
2. Экзотика (Thrift, GraphQL, WebSocket) — командная специфика, не требование по умолчанию; достаточно понимать концепции.
3. Во всех вакансиях упоминаются микросервисы — готовь рассказ о своём опыте: как делил сервисы, как организовывал коммуникацию, как решал распределённые проблемы.
4. Unit-тесты упоминаются как обязательные — подготовь ответы про JUnit 5, Mockito, тестовые стратегии (пирамида тестирования, testcontainers).
