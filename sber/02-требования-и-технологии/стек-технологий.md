# Технологический стек Сбера для Java-бэкендера

Собрано из реальных вакансий (СберИнвестор, СберТранспорт, СберПраво, ППРБ, Sberbank.ru) и описания Platform V.

## Обязательный минимум (есть почти в каждой вакансии)

| Область | Технологии |
|---|---|
| Язык | **Java 11 / 17** (встречается 21), Lombok |
| Фреймворк | **Spring Boot**, Spring Framework (Core, MVC, Data, Security, AOP) |
| БД | **PostgreSQL** (целевая СУБД Сбера — Platform V Pangolin), уверенный SQL |
| ORM | **Hibernate / JPA**, реже MyBatis |
| Миграции | **Liquibase** (иногда Flyway) |
| Очереди | **Apache Kafka** (принципы очередей сообщений — спрашивают всегда) |
| Сборка | Gradle / Maven |
| Контейнеры | **Docker, Kubernetes / OpenShift** (OpenShift — стандарт Сбера) |
| Тесты | JUnit 5, Mockito, unit-тестирование — обязательное требование |
| Архитектура | **Микросервисы**, REST API |

## Часто встречается (плюсом)

- gRPC, Thrift, WebSocket, GraphQL (СберИнвестор)
- Redis (кеширование)
- CI/CD: Jenkins, GitLab CI
- Service Mesh: Istio, Envoy (Platform V Synapse)
- Мониторинг: Prometheus, Grafana
- ELK / логирование
- Apache Flink (стриминг), Ceph (хранилище) — в платформенных командах
- Application servers: WildFly (легаси-команды)
- Camunda / BPM (процессные команды банка)

## Внутренние технологии Сбера (знать на словах — плюс)

- **Platform V** — внутренняя платформа разработки (90+ продуктов, 300+ микросервисов).
- **Platform V DataSpace** — BaaS для бэкенда с Java SDK.
- **Platform V Synapse** — интеграция/Service Mesh (Istio + Envoy + Kubernetes).
- **Platform V Pangolin** — корпоративная сборка PostgreSQL.
- Контекст импортозамещения: миграция с Oracle на PostgreSQL — опыт таких миграций ценится.

## Типичные требования по грейдам

**Middle (2+ года опыта):**
- Уверенный Java Core, коллекции, многопоточность.
- Spring Boot: REST-сервисы, Data JPA, транзакции.
- SQL: джойны, индексы, планы запросов.
- Kafka: базовые гарантии, партиции, consumer groups.
- Docker, базовый Kubernetes, Git, code review.

**Senior (4–5+ лет):**
- Всё выше + глубокое понимание JVM (GC, память, JIT).
- Проектирование микросервисной архитектуры, паттерны (Saga, Outbox, Circuit Breaker).
- System design: масштабирование, отказоустойчивость, консистентность.
- Производительность: профилирование, оптимизация запросов, кеширование.
- Менторинг, декомпозиция задач бэклога, анализ инцидентов.
