# Устройство в Сбер: Java Backend Developer — полный гайд

> Собрано: июнь 2026. Цель — оффер на позицию Java-бэкендера в Сбер (Сбербанк / СберТех / дочерние компании).

## TL;DR

1. **Процесс найма**: HR-звонок → техническая секция (Java + теория + лайвкодинг) → System Design (для Senior+) → HR-интервью (софт-скиллы) → финальная встреча с командами. Весь цикл ~1 неделя (или 1 день на «1 Day Offer»). Все этапы удалённо.
2. **Фирменная фишка Сбера**: код-ревью с поиском скрытых багов («найди 8 багов в классе») — проверяют знание контрактов языка (equals/hashCode, Serializable/Externalizable, clone). Алгоритмов меньше, чем в Яндексе, — больше «как это работает под капотом».
3. **Стек**: Java 11/17/21, Spring Boot, PostgreSQL, Kafka, Hibernate, Docker, Kubernetes/OpenShift, Liquibase, Gradle/Maven + собственная Platform V.
4. **Вопрос-«убийца»**: self-invocation в `@Transactional` (валит 9 из 10 кандидатов). Разбор — в `03-вопросы-собеседований/spring.md`.
5. **Зарплаты (2026)**: Middle (грейды 12–13) ~250–350k ₽, Senior (грейд 14) 400–600k ₽ + годовые бонусы 2–3 оклада + LTI.

## Структура папки

| Папка | Содержимое |
|---|---|
| `00-hr-скрининг/` | Q&A для HR-этапа (достижения, провалы, причины ухода) + эталонное резюме с разбором, почему оно проходит фильтры |
| `01-компания-и-процесс/` | Этапы найма, 1 Day Offer, подразделения Сбера, зарплаты и грейды |
| `02-требования-и-технологии/` | Стек из реальных вакансий, Platform V, типовые требования |
| `03-вопросы-собеседований/` | Вопросы по темам + парные файлы `ответы-*.md` с краткими ответами для самопроверки (116 Q&A: Java Core, Spring, SQL, многопоточность, Kafka/микросервисы) |
| `04-тестовые-задания/` | Фирменная задача «8 багов», лайвкодинг (16 задач), практические задачи middle/senior (LRU, rate limiter и др.), SQL-задачи — всё в формате «условие → решение» |
| `05-книги-и-ресурсы/` | Книги, которые рекомендует сам Сбер, + ссылки на все источники |
| `06-план-подготовки/` | План подготовки на 4 недели и чеклист перед собеседованием |

## С чего начать

1. Прочитай `01-компания-и-процесс/процесс-найма.md` — пойми, что тебя ждёт.
2. Пройди `03-вопросы-собеседований/топ-12-вопросов-банков.md` — это 80% вопросов на банковских Java-собесах.
3. Прорешай `04-тестовые-задания/код-ревью-8-багов.md` — визитная карточка Сбера, затем `лайвкодинг-задачи.md`, `практические-задачи.md` и `sql-задачи.md`.
4. Следуй плану из `06-план-подготовки/план-4-недели.md`.
5. Подавайся: [rabota.sber.ru/search/?query=java](https://rabota.sber.ru/search/?query=java) и лови события «1 Day Offer» (закрывают 25% Java-вакансий за день).
