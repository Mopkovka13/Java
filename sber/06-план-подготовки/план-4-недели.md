# План подготовки: 4 недели до оффера

Рассчитан на работающего Middle/Middle+ разработчика, ~1.5–2 часа в будни, 3–4 часа в выходные. Если опыта больше — сжимай до 2 недель, пропуская знакомое.

## Неделя 1 — Java Core и контракты (фокус Сбера)

- [ ] Прочитать `03-вопросы-собеседований/java-core.md`, закрыть пробелы через enhorse/java-interview.
- [ ] Effective Java: items про equals/hashCode (10–11), toString, Comparable, immutability (15–17), builder.
- [ ] Контракты: equals/hashCode, Serializable/Externalizable, Cloneable — **прорешать задачу «8 багов»** (`04-тестовые-задания/`).
- [ ] Коллекции под капотом: HashMap (рассказать вслух за 5 минут), ArrayList, TreeMap, ConcurrentHashMap.
- [ ] Stream API: прорешать задачи 1, 2, 7 из `04-тестовые-задания/лайвкодинг-задачи.md`.
- [ ] LeetCode: 10 easy (strings, arrays, hash table).

## Неделя 2 — Spring и БД

- [ ] `03-вопросы-собеседований/spring.md`: жизненный цикл бина, прокси, **self-invocation @Transactional** (вопрос-убийца — рассказать вслух с 4 решениями).
- [ ] Все 7 propagation + rollbackFor (checked не откатывает!) — написать демо-проект и проверить руками.
- [ ] Spring Data JPA: N+1 (воспроизвести и починить тремя способами), LazyInitializationException, @Version.
- [ ] SQL: джойны, оконные функции — прорешать 4 запроса из `базы-данных-sql.md` + [sql-ex.ru или LeetCode Database].
- [ ] PostgreSQL: уровни изоляции + MVCC — уметь объяснить за 5 минут; EXPLAIN ANALYZE на своём проекте.
- [ ] LeetCode: 8 easy/medium.

## Неделя 3 — Многопоточность, Kafka, инфраструктура

- [ ] Java Concurrency in Practice гл. 1–7 (или конспект): JMM, happens-before, volatile, публикация.
- [ ] Написать руками: потокобезопасный singleton, producer-consumer (wait/notify И BlockingQueue), пример deadlock + фикс.
- [ ] ThreadPoolExecutor: нарисовать схему «что происходит с задачей» (core → queue → max → rejection).
- [ ] CompletableFuture: 3–4 упражнения на композицию.
- [ ] Kafka: партиции/ключи/порядок, consumer groups, гарантии доставки, идемпотентность — `kafka-микросервисы.md`.
- [ ] Паттерны: Saga, Outbox, Circuit Breaker — уметь рассказать с примером из своего опыта (или придумать, как применил бы).
- [ ] Docker/K8s: liveness/readiness, JVM в контейнере, CPU throttling (вопрос из топ-12).
- [ ] LeetCode: 8 medium.

## Неделя 4 — Интеграция и репетиции

- [ ] Прогнать `топ-12-вопросов-банков.md` — ответить вслух на все 12 с примерами кода.
- [ ] System design (Senior): 2 задачи с таймером 45 мин — «платёжная система» и «уведомления» (`system-design.md`).
- [ ] Софт-скиллы: 4 STAR-истории записать и отрепетировать (`софт-скиллы-финал.md`).
- [ ] Мок-интервью: попроси коллегу или прогони себя по списку, записывая на диктофон.
- [ ] Резюме: подогнать под стек Сбера (Java 17, Spring Boot, PostgreSQL, Kafka, Docker/OpenShift, микросервисы), цифры и результаты в каждом пункте опыта.
- [ ] Подать отклики: rabota.sber.ru + hh.ru + следить за анонсами 1 Day Offer.
- [ ] Накануне собеса: `06-план-подготовки/чеклист.md`.

## Параллельно всё время

- 1–2 задачи LeetCode в день (easy/medium) — не для алгоритмов ради алгоритмов, а для скорости чистого кода под наблюдением.
- Читай инженерный блог Сбера на Хабре — будет о чём спросить на финале.
