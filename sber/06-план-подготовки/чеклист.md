# Чеклист перед собеседованием в Сбер

## За день до

- [ ] Прогнать вслух топ-12 вопросов (`../03-вопросы-собеседований/топ-12-вопросов-банков.md`), особенно:
  - self-invocation @Transactional + 4 решения
  - HashMap под капотом
  - уровни изоляции + MVCC PostgreSQL
  - N+1 и решения
  - Kafka: ключ → партиция → порядок
- [ ] Перерешать задачу «8 багов» с чистого листа.
- [ ] Освежить 4 STAR-истории (инцидент, решение, конфликт, ошибка).
- [ ] Подготовить 5+ своих вопросов команде.
- [ ] Перечитать описание вакансии — соотнести каждый пункт требований со своим опытом.

## Техническая подготовка (собес удалённый)

- [ ] Проверить камеру, микрофон, интернет; запасной канал (телефон-хотспот).
- [ ] Открыть чистую IDE (IntelliJ IDEA) — лайвкодинг может быть в ней с расшариванием экрана.
- [ ] Закрыть всё лишнее на экране. **Никаких AI-помощников** — прямой запрет Сбера.
- [ ] Тихое место, вода рядом, блокнот для заметок.

## Во время собеседования

- [ ] Уточняй условие задачи до начала кодинга (это оценивается как плюс).
- [ ] Размышляй вслух; застрял — говори, о чём думаешь: интервьюеры Сбера помогают.
- [ ] «Не знаю, но рассуждал бы так...» лучше, чем молчание или блеф.
- [ ] Не критикуй бывших работодателей. Про команду — «мы», про свой вклад — «я».
- [ ] После решения сам прогони граничные случаи и назови сложность.
- [ ] В конце задай свои вопросы — отсутствие вопросов читают как незаинтересованность.

## После

- [ ] В тот же день записать все вопросы, на которых плавал, — разобрать до следующего этапа.
- [ ] Если не ответили за 5–7 дней — вежливо напомнить рекрутеру.
- [ ] Отказ ≠ конец: в Сбере сотни команд, можно пробовать в другую через 3–6 месяцев, кандидатов сохраняют в базе.

## Резюме — быстрый чеклист

- [ ] Ключевые слова стека Сбера: Java 11/17, Spring Boot, PostgreSQL, Kafka, Hibernate, Docker, Kubernetes/OpenShift, микросервисы, Liquibase, JUnit/Mockito.
- [ ] Каждый пункт опыта — с результатом и цифрой («снизил латентность отчёта с 12с до 800мс», «сервис на 5k RPS»).
- [ ] Без воды: 1–2 страницы.
- [ ] Опыт с высоконагруженными/финансовыми системами — выделить.
