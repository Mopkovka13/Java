# Книги для подготовки

## Рекомендованы официально Сбером (из гайда developers.sber.ru)

1. **«Spring в действии»** — Крейг Уоллс. Базовая книга по Spring/Spring Boot.
2. **«Чистая архитектура»** — Роберт Мартин. Принципы проектирования, SOLID.
3. **«Java Concurrency in Practice»** — Brian Goetz. Библия многопоточности; темы оттуда спрашивают дословно (JMM, happens-before, публикация объектов).
4. **«Паттерны проектирования»** (Head First Design Patterns) — Эрик Фримен, Элизабет Робсон. Паттерны GoF доступно.
5. **«Designing Data-Intensive Applications»** — Martin Kleppmann. Для System Design секции (Senior+). Ключевые главы: репликация, партиционирование, транзакции, консистентность.

## Стоит добавить (де-факто стандарт Java-собеседований)

6. **«Effective Java» (3-е изд.)** — Joshua Bloch. Items про equals/hashCode, builder, immutability — прямые ответы на вопросы Сбера, включая задачу «8 багов».
7. **«Java. Полное руководство»** или **«OCP Study Guide»** — если нужно систематизировать Java Core.
8. **«High-Performance Java Persistence»** — Vlad Mihalcea. Hibernate/JPA глубоко: N+1, блокировки, батчинг — банковские темы.
9. **«Kafka: The Definitive Guide»** — Narkhede и др. (или бесплатно: документация Confluent).
10. **«System Design Interview» т.1–2** — Alex Xu. Структура ответа на дизайн-секции.
11. **«Чистый код»** — Роберт Мартин. Для код-ревью секции.
12. **«Грокаем алгоритмы»** — Адитья Бхаргава. Если алгоритмическая база слабая — быстрый вход.

## Приоритет чтения при ограниченном времени

| Грейд | Минимальный набор |
|---|---|
| Middle | Effective Java (ключевые items) + Spring в действии + Java Concurrency in Practice (гл. 1–7) |
| Senior | + Kleppmann + Mihalcea + Alex Xu |
