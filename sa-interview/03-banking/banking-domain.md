# Банковский домен (для Сбера и финтеха)

Знание домена сильно усиливает кандидата. Здесь — специфика банковских систем, термины, кейсы.

---

## Базовые понятия

### 🟢 Вопрос: Расскажи про основные банковские сущности.

- **Счёт (account)** — учётная запись для денег клиента (расчётный, текущий, карточный, депозитный, ссудный). Имеет номер (20 знаков по плану счетов ЦБ), валюту, остаток.
- **Карта** — инструмент доступа к счёту (дебетовая/кредитная). Имеет PAN (номер), срок, CVV.
- **Проводка (transaction/posting)** — запись о движении средств.
- **Дебет/Кредит** — стороны бухгалтерской проводки (двойная запись).
- **Баланс/остаток** — текущая сумма на счёте; различают **доступный** и **фактический** (с учётом холдов).
- **Холд (авторизационная блокировка)** — временно замороженная сумма (например, при оплате до списания).

### 🟢 Вопрос: Что такое дебет и кредит простыми словами?

В бухучёте каждая операция отражается дважды (**двойная запись**): по дебету одного счёта и кредиту другого. Для клиентского счёта: поступление денег и списание отражаются проводками так, что сумма дебетов = сумме кредитов. Главное для аналитика — понимать принцип двойной записи и что баланс не должен «разъезжаться».

### 🟡 Вопрос: Что такое эквайринг?

Приём безналичных платежей по картам. Участники: **держатель карты → банк-эмитент** (выпустил карту) → **платёжная система** (Visa/MC/МИР) → **банк-эквайер** (обслуживает торговую точку) → **мерчант** (магазин). Эквайер зачисляет деньги мерчанту за вычетом комиссии.

## Платежи и переводы

### 🟡 Вопрос: Как работает перевод между счетами? Опиши логику.

```
1. Валидация: счета существуют, активны, валюты совместимы.
2. Проверка лимитов и достаточности средств (доступный остаток).
3. Антифрод-проверка.
4. Транзакция (атомарно):
   - списать со счёта отправителя (дебет),
   - зачислить на счёт получателя (кредит).
5. Фиксация проводок, обновление балансов.
6. Уведомление сторон.
```
Ключевое: **атомарность** (ACID/транзакция или Saga в распределённой системе), **идемпотентность** (повтор не должен списать дважды), аудит.

### 🟡 Вопрос: Что такое СБП?

**Система быстрых платежей** (ЦБ РФ) — мгновенные переводы по номеру телефона между банками 24/7, оплата по QR. Оператор — ЦБ + НСПК. Аналитику важно: переводы C2C по телефону, идентификация банка получателя, лимиты, мгновенность (асинхронность с гарантией).

### 🟡 Вопрос: Какие платёжные системы и стандарты знаешь?

- **Платёжные системы:** Visa, Mastercard, **МИР** (НСПК), UnionPay.
- **СБП, СПФС** (аналог SWIFT в РФ), **SWIFT** (международные).
- **ISO 20022** — международный стандарт финансовых сообщений (постепенно заменяет SWIFT MT). Знание ISO 20022 — плюс.
- **ISO 8583** — стандарт сообщений по карточным транзакциям.

### 🟡 Вопрос: Что такое клиринг и расчёты (settlement)?

- **Клиринг** — взаимозачёт встречных требований между банками (определение, кто кому должен).
- **Расчёт (settlement)** — фактическое перечисление денег по итогам клиринга. Обычно отложено (T+1), поэтому авторизация (холд) и списание разнесены во времени.

## Антифрод и комплаенс

### 🟡 Вопрос: Что такое антифрод?

Система выявления мошеннических операций. Анализирует транзакции по правилам и ML-моделям: нетипичная сумма, география, частота, устройство, поведение. Решения: пропустить / запросить подтверждение / заблокировать. Аналитик описывает правила, события, пороги, действия.

### 🟡 Вопрос: Что такое KYC и AML?

- **KYC (Know Your Customer)** — идентификация клиента (документы, проверка).
- **AML (Anti-Money Laundering)** — противодействие отмыванию денег (115-ФЗ в РФ). Мониторинг подозрительных операций, сообщения в Росфинмониторинг.
- **ПОД/ФТ** — противодействие отмыванию и финансированию терроризма.

### 🟡 Вопрос: Что такое 3-D Secure?

Протокол дополнительной аутентификации при онлайн-оплате картой (подтверждение по SMS/push/биометрии). Снижает фрод, переносит ответственность. Версия 2.0 — более гибкая, риск-ориентированная.

## Регуляторика РФ

### 🟡 Вопрос: Какие регуляторные требования важны в банке?

- **152-ФЗ** — персональные данные.
- **115-ФЗ** — ПОД/ФТ (AML).
- **161-ФЗ** — национальная платёжная система.
- **Положения и стандарты ЦБ РФ** (например, по информбезопасности — ГОСТ 57580).
- **PCI DSS** — безопасность карточных данных.
- Отчётность в ЦБ.

Аналитик учитывает это в требованиях: хранение и шифрование данных, аудит, маскирование PAN, согласия, лимиты.

## Практические банковские кейсы

### 🔴 Кейс: Спроектируй сервис перевода денег между клиентами банка.

**Уточняющие вопросы:** внутрибанковский или межбанковский (СБП)? Лимиты? Валюты? Синхронный или асинхронный ответ? Нагрузка? Требования к согласованности?

**Функциональные требования:** валидация, проверка средств, антифрод, списание/зачисление, уведомления, история операций.

**NFR:** идемпотентность, атомарность (никогда не списать без зачисления), согласованность (CP), доступность 99,9%+, RPO≈0, аудит, p95 ≤ 1–2 с.

**Архитектура:** API → сервис переводов → транзакция в БД / Saga при распределённости; идемпотентность по ключу; outbox для событий; антифрод-сервис (синхронно при пороговых суммах); уведомления через брокер.

**Обработка ошибок:** недостаточно средств (409), счёт заблокирован (403), антифрод-стоп, таймаут внешнего сервиса → компенсация/откат.

### 🔴 Кейс: Как обеспечить, что деньги не спишутся дважды?

- **Идемпотентный ключ** на запрос перевода (клиент генерирует, сервер дедуплицирует).
- **Атомарная транзакция** списание+зачисление (или Saga с компенсацией).
- Проверка статуса операции перед повтором.
- Уникальный constraint на (idempotency_key) в БД.

### 🔴 Кейс: Интеграция с бюро кредитных историй (БКИ).

Синхронный запрос с таймаутом + кэширование результата на короткий срок; обработка недоступности (retry/circuit breaker); согласие клиента (ПДн); логирование запросов; fallback-сценарий, если БКИ недоступно (отложить решение/ручная проверка).

## Словарь банковских терминов

| Термин | Значение |
|--------|----------|
| ДБО | Дистанционное банковское обслуживание (интернет/мобайл-банк) |
| АБС | Автоматизированная банковская система (ядро/core banking) |
| ПЦ | Процессинговый центр (обработка карточных операций) |
| РКО | Расчётно-кассовое обслуживание |
| Эмитент | Банк, выпустивший карту |
| Эквайер | Банк, обслуживающий приём карт |
| Реестр | Файл-выгрузка операций для сверки |
| Сверка (reconciliation) | Сопоставление операций между системами |
| Овердрафт | Кредитование при нехватке средств на счёте |
| Холд | Авторизационная блокировка суммы |
| Фондирование | Источник средств банка |

## Чит-лист по банкам

- Понимай: счёт, карта, проводка, двойная запись, холд, доступный остаток.
- Перевод: атомарность + идемпотентность + антифрод + аудит.
- СБП — мгновенные переводы по телефону через ЦБ/НСПК.
- KYC/AML (115-ФЗ), 152-ФЗ, PCI DSS, 3-D Secure.
- Стандарты: ISO 20022, ISO 8583, SWIFT/СПФС.
- Для денег: согласованность важнее доступности (CP), RPO≈0.
