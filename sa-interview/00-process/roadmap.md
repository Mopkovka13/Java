# План подготовки и грейды

## Грейды системного аналитика

| Грейд | Что ожидают | Глубина тем |
|-------|-------------|-------------|
| 🟢 **Junior** | Знает теорию: виды требований, базовые нотации (BPMN/UML), простой SQL, что такое REST/API. Может писать User Story. Работает под присмотром. | Теория + база SQL + основы API |
| 🟡 **Middle** | Самостоятельно ведёт фичу/проект: собирает требования, проектирует интеграции и модель данных, пишет ТЗ/спеки, понимает архитектуру, очереди, нефункциональные требования. | Всё + системный дизайн фичи + интеграции + БД глубоко |
| 🔴 **Senior / Lead** | Проектирует системы и сложные интеграции, отвечает за архитектурные решения и трейд-оффы, нефункциональные требования, наставничество, работа со стейкхолдерами на уровне продукта. | Архитектура, NFR, отказоустойчивость, лидерство |

## Приоритеты по времени (если времени мало)

## Карта самопроверки

Перед собесом ты должен уметь без подготовки:
- [ ] Объяснить разницу функциональных и нефункциональных требований с примерами
- [ ] Написать SELECT с JOIN, GROUP BY, HAVING и подзапросом
- [ ] Нарисовать BPMN-диаграмму простого процесса
- [ ] Нарисовать sequence-диаграмму взаимодействия сервисов
- [ ] Объяснить разницу REST vs SOAP, синхрон vs асинхрон
- [ ] Объяснить, что такое идемпотентность и зачем она в платежах
- [ ] Написать User Story с критериями приёмки в Gherkin
- [ ] Рассказать про нормализацию БД (1НФ, 2НФ, 3НФ)
- [ ] Объяснить, что такое транзакция и ACID
- [ ] Рассказать STAR-историю про конфликт и про ошибку
