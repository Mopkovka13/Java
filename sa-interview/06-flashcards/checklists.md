## ✅ Чек-лист «Готов к техническому интервью»

### Требования
- [ ] Объясню разницу FR и NFR с примерами
- [ ] Назову уровни требований (бизнес/пользовательские/системные)
- [ ] Напишу User Story + критерии приёмки в Gherkin
- [ ] Назову техники сбора и методы приоритизации (MoSCoW/RICE)
- [ ] Расскажу про свойства хорошего требования

### Нотации
- [ ] Нарисую BPMN простого процесса, объясню пул/дорожку/шлюзы
- [ ] Нарисую sequence-диаграмму взаимодействия сервисов
- [ ] Объясню Use Case (актёр, include/extend)
- [ ] Нарисую ERD, реализую связь M:N
- [ ] Знаю, когда применять state machine, activity, C4

### SQL и БД
- [ ] Напишу SELECT с JOIN, GROUP BY, HAVING, подзапросом
- [ ] Напишу оконную функцию (ROW_NUMBER/RANK, running total)
- [ ] Объясню порядок выполнения запроса
- [ ] Расскажу про нормализацию (1-3НФ) и денормализацию
- [ ] Объясню индексы (плюсы/минусы, когда не нужны)
- [ ] Расскажу про транзакции, ACID, уровни изоляции
- [ ] Найду клиентов без заказов (LEFT JOIN + IS NULL)
- [ ] Помню про подвохи с NULL

### API и интеграции
- [ ] HTTP-методы + идемпотентность + коды ответов
- [ ] Разница 401/403, REST vs SOAP
- [ ] Объясню идемпотентность и Idempotency-Key
- [ ] Синхрон vs асинхрон, когда что
- [ ] Спроектирую CRUD REST API
- [ ] Расскажу про OpenAPI/Swagger
- [ ] Знаю gRPC, GraphQL — когда применять

### Брокеры и архитектура
- [ ] Зачем брокер, Kafka vs RabbitMQ
- [ ] Партиции/offset/consumer group, порядок в Kafka
- [ ] Гарантии доставки, DLQ
- [ ] Outbox, Saga
- [ ] Монолит vs микросервисы (плюсы/минусы)
- [ ] API Gateway, балансировка, масштабирование
- [ ] Репликация vs шардирование, Circuit Breaker

### Безопасность
- [ ] Аутентификация vs авторизация
- [ ] JWT (устройство), OAuth2 (flow), access/refresh
- [ ] RBAC/ABAC, шифрование at rest/in transit
- [ ] 152-ФЗ, PCI DSS (для банков)

### NFR
- [ ] Виды NFR, как формулировать измеримо
- [ ] latency/throughput, p95/p99
- [ ] Доступность (девятки), SLA/SLO/SLI
- [ ] RTO/RPO, отказоустойчивость

### Банки (для финтеха/Сбера)
- [ ] Счёт, карта, проводка, двойная запись, холд
- [ ] Логика перевода (атомарность + идемпотентность)
- [ ] СБП, эквайринг, эмитент/эквайер
- [ ] KYC/AML, 3-D Secure, регуляторика РФ
- [ ] Стандарты: ISO 20022, ISO 8583, SWIFT
